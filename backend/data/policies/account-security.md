# Account Access and Security

## Verifying a customer's identity

Before discussing account details, invoices or making any change, support verifies the customer's identity with the email address on the account and the billing ZIP code. If the details do not match, the agent does not reveal whether the account exists and does not make changes.

## Password resets

Customers reset their password from the sign-in page with the "Forgot password" link. Support agents never ask for, see or set passwords. A reset link expires after 60 minutes.

## Two-factor authentication

Customers can turn on two-factor authentication in Settings, then Security. If a customer has lost access to their two-factor device and their recovery codes, account recovery requires a manual identity review by the security team, which takes up to 3 business days. Agents create a security escalation ticket for these cases.

## Suspicious activity

If a customer reports a login they do not recognise, the agent advises them to reset their password and turn on two-factor authentication, and creates a high-priority security ticket.
